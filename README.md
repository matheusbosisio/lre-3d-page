# LRE 3D Criativo

Site institucional e vitrine de produtos da LRE 3D Criativo, loja de impressão 3D em João Pessoa, PB.

## Publicação

O projeto é um site estático. Basta abrir `index.html` ou publicar a pasta em qualquer serviço de hospedagem estática, como a Vercel.

## Antes de divulgar

Substitua o número de exemplo `5583900000000` pelo WhatsApp real da loja em todos os links do `index.html`.
